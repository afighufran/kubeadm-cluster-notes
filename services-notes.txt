untuk pake nodeport
kubectl expose deployment nama_deployment --type=NodePort --port=port_default_servicenya

untuk pake clusterip
kubectl expose deployment nama_deployment --port=port_default_servicenya
cluster ip tidak perlu menyebutkan type karena itu default

untuk mengubah tipe service, dalam kasus ini diubah menjadi loadbalancer
kubectl patch svc nama_deployment -p '{"spec": {"type": "LoadBalancer"}}'
